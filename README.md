# Guía Diseño Accesible Correos — Beyonder × Sony Music

Documentos HTML estáticos: guías, propuestas y minutas para Sony Music. Cada documento es autocontenido (un solo archivo, sin dependencias externas), responsivo, y trae switch ES/EN.

## Contenido

| Archivo | Tipo | Documento |
|---|---|---|
| `index.html` | Índice | Portada con enlace a cada documento |
| `guia-accesibilidad-correos.html` | Presentación (15 slides) | Diseño accesible para correos |
| `propuesta-recaps-somosfiltr.html` | Documento A4 | Galería de Recaps para eventos SomosFiltr |
| `minuta-centro-america.html` | Documento A4 | Minuta — Reunión Equipo Centro América |
| `master-template.html` | Documento A4 | Master Template (base modular) |

## Deploy en Vercel

Sitio estático, sin build step.

1. En [vercel.com](https://vercel.com) → **Add New** → **Project**
2. Importa este repositorio
3. Framework Preset: **Other**
4. Build Command: dejar vacío · Output Directory: `site`
5. **Deploy**
